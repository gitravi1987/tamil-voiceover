# Legal & ethics

- **Personal, non-commercial, family use only.** Not affiliated with or endorsed by Netflix.
- **No DRM circumvention.** The extension never decrypts, records, downloads or redistributes Netflix audio or video. It only reads subtitle text already displayed on the user's own screen (cf. India Copyright Act s.65A; Netflix Terms of Use).
- **No redistribution** of translated subtitle files or dubbed audio.
- **Privacy:** subtitle lines are sent only to the translation/TTS APIs the user chooses. API keys stay on the user's machine.
- **Before going public:** check that git history has no secrets; use no Netflix footage in posts (blur or audio-only demos).
